# OSHĪ — Luxury Sri Lanka Travel & Chauffeur Services

Private, design-led journeys and chauffeur-driven transport across Sri Lanka's UNESCO heritage fortresses, misted tea country, leopard sanctuaries, and golden south coast.

## Project Structure

- `front_end/oshi-app`: Next.js 16 (App Router), React 19, Tailwind CSS v4, Framer Motion, GSAP, Leaflet, and Clerk Auth.
- `backend`: Node.js, Express 5, TypeScript, MongoDB (Mongoose), Nodemailer, and Clerk Auth.

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd front_end/oshi-app
npm install
npm run dev
```
